# Публикация наведения native-intervals-v1

Опубликована ранее отдельно проверенная сборка наведения. Исполняемое
содержимое не менялось после её подготовки: SHA-256
`6011ef3669a83183881e40d57d1185363d8e24c9ee0927b44f333e2a28053d4f`.
Свежая загрузка `https://devast.io/js/8arQWmH5bsutMu.js` снова дала основу
с SHA-256 `ba2ec29027d11f955c7a03d12380461750a5d28cf51ac575196fbc5ac651d358`.

Включены штатные пороги отправки углов: 150 мс без стрельбы, 60 мс при
стрельбе, с разрешением отправки после превышения порога. Расчёт цели и
упреждения сохранён. Ожидающих обновлений не больше одного, вычисление
повторяется на свежих координатах; смерть и потеря соединения отменяют его.
Подробности первоначальной подготовки — в AIM-TRANSPORT-REVIEW.md.
Три проверенных удаления предыдущего выпуска сохранены. Другие проверки
на основании догадок не удалялись. Штатный heartbeat `[0]` сохранён.

В отчёте пользователя отсутствовал идентификатор нового транспорта, а углы
продолжали отправляться примерно раз в 50 мс. Это не проверка поведения
native-intervals-v1. Для устранения неоднозначной загрузки обновлён стабильный
`dist/game.modded.js` и добавлен небольшой импортируемый файл
`dist/Devast-aim-pacing.ResourceOverride.json`.

Это правило загружает `main/dist/game.modded.js` через XHR с новым параметром
URL при каждом открытии страницы; внутри не хранится старая копия игры.
Оно продолжает использовать main после дальнейших выпусков или отката.
Для проверки нужно отключить старое правило, импортировать это и перезагрузить
страницу. В консоли:

```js
window.__devastMod.snapshotDiagnostics().aimTransport
```

Ожидается `native-intervals-v1`. Отсутствующее значение означает, что новый
транспорт не подтверждён в этой вкладке. Нельзя считать такой запуск
проверкой данного выпуска.

Ранее пройдены 69 JavaScript-тестов и 12 Python-тестов, симуляция 20 минут
и загрузка клиента в браузере. Перед этой публикацией отдельно выполнены
шесть целевых тестов наведения и кодирования, 12 Python-тестов, пересборка
из свежей основы и проверка синтаксиса. Новые тесты сравнили все 360 углов
с обычным поворотом мышью через настоящий нативный WebAssembly-кодировщик.
Новые проверки AutoFire в расследовании не выполнялись. Штатный полный
набор CI остаётся регрессионной проверкой проекта.

Причина сообщённого серверного отключения всё ещё не установлена.
Отсутствие флага клиентской проверки или совпадение формата пакетов не
исключает оценку обычного поведения сервером. Длительной сетевой проверки
наведения для этого выпуска не было. Выпуск устраняет установленное
расхождение отправки и проблему загрузки прежней версии; он не объявляется
исправлением всех киков или средством невидимости для серверного античита.

Предыдущий main сохранён в ветке
`backup/before-aim-pacing-20261030-200359` на коммите
`7c6084e402630478e050d5a9ea716576277504b2`.
Выпуск отмечен тегом `aim-pacing-20261030-200359`; полный откат одним
обратным коммитом описан в ROLLBACK.md. Пользовательские диагностические
трассы и браузерные профили в публикацию не включены.

Ограничение отправки углов позднее отменено после сообщения о регрессии.
Текущий выпуск описан в AIM-DIRECT-RESTORE.md.
